安全な初期化ガイド

  1. PostgreSQL を起動し、Web の Terminal だけに接続情報を設定します。
  2. .venv/bin/operamind-migrate を実行して Migration を整合させます。
  3. 隔離 linked worktree を VS Code で開き、Workspace Trust を自分で確認します。
  4. operaMind MCP を起動し、「OperaMind: ローカル環境を診断」を実行します。
  5. GitHub Copilot Chat のサインインと Credit／Quota を実会話前に確認します。

OperaMind は Workspace Trust、認証情報、Migration を自動変更しません。
