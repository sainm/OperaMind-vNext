安全な初期化ガイド

  1. PostgreSQL を起動し、Web 用ターミナルだけに接続情報を設定します。
  2. .venv/bin/operamind-migrate を実行してデータベース構造を更新します。
  3. 隔離された作業ディレクトリを VS Code で開き、ワークスペースの信頼を自分で確認します。
  4. operaMind MCP を起動し、「OperaMind: ローカル環境を診断」を実行します。
  5. GitHub Copilot Chat のサインインと利用上限を実会話前に確認します。

OperaMind はワークスペースの信頼、認証情報、データベース構造を自動変更しません。
